Line figures, round 3: real 3D bodies

Meta's SAM 3D Body model fitted a full 3D body to each exercise photo. Every figure is turned to the same three-quarter side view, with the same body size and floor. Limbs now bend at the joints and keep their length while moving. Light mode is style B, dark mode style C.

What's new

Real proportions from a 3D body, not from a flat photo. Bars are drawn in 3D through both hands, so they tilt and turn correctly and never disappear. The Lying Leg Curl now works.

Line or mannequin?

Pick one for the app. Both use the same data and the same size. The mannequin looks more human; the line figure is cleaner when small.
